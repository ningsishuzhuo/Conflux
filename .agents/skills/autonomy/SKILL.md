# 自主推进

## 开工契约冻结

动工前与用户确认并冻结以下四项：

1. 任务 DAG、依赖及独立 worktree 划分。
2. 验收命令由协调者持有，执行者不得修改；验收时核对命令及对应测试未被执行者篡改。
3. 本次 Run 红线：禁止 `git push`、删库、擅改需求和绕过付费授权。
4. Claude 终审触发节点：复杂项目开工拍砖、大里程碑收口、Codex 连续卡死兜底；每个节点仍须绑定本次显式付费授权。

## 四角色静默闭环

- 遵循 `AGENTS.md` 正向路由：Antigravity 协调、决策与验收。
- 免费 DSH 承担只读调研、确定性验收跑腿（只吐结构化事实）和小范围机械改动；仅给一次机会，脏工作区交 Codex。
- Codex 承担核心实现与修复；Claude 按冻结节点和付费授权参与终审。
- 执行生命周期、DAG 依赖、事件唤醒和重试交给 Orca 原生 `orchestration` 指南；不轮询，不自建状态文件。

## 返工与熔断

- 验收不通过时附旧证据打回重做。
- 同一任务连续失败或返工超过冻结上限（默认 2～3 次）时熔断。
- 遇到需求歧义、返工熔断、触及付费或高危红线、外部基础设施故障时，调用 Orca 原生 `gate` 暂停叫人；具体命令见原生 `orchestration` 指南。

## 里程碑防失忆

每个阶段验收通过后，由执行者做本地 `git commit`；协调者用 Conflux 6 行 `handoff publish/verify` 落盘索引，不维护第二份实时状态。
