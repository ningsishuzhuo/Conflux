# 异常与收口

## API 重试止损

Claude 审查或点名咨询出现 `modelWait: retrying`（含 409/429/502/其他 5xx）立即 `worker-stop`。若本轮 Claude 用于 Codex 熔断救场，或替补不可用，停止并 `gate-create` 叫人。其余情况直接切全新独立上下文 Codex（免再追问），并在 `worker_done`/交付首行标注 `已自动降级为 Codex（原因：API 重试止损）`。

## Claude gate 与内联审查

按 AGENTS.md 判断本次授权；需要确认时以 `gate-create` 绑定本次任务与用途。内联 DSH 摘要，标明审阅对象及其版本，禁业务/仓库 shell 与扫仓，仅放行最后的 `worker_done`，总输出 ≤ 25 行，回执摘要 ≤ 20 行。

## 打回与软伤收口

失败指纹采用稳定测试 ID 或稳定清单条目，行号仅用于定位。回执和打回单原样带指纹，计次直读 `worker-list` 与 `inbox` 的既有记录。
打回单固定四行：
1. 快照、Task/Dispatch ID 和本轮次数。
2. 硬伤及原样指纹、实测证据。
3. 软伤及原样指纹，独立列出，软伤不阻塞硬伤结论。
4. 可写范围、冻结复验方法和停止条件。
无硬伤但有可修软伤时自动收口一次，仅限已在 diff 内的文件；非 git 目录改前先 `cp -a` 快照，并按冻结改动文件清单限制范围。按原标准复验；变红时先核对无并发修改，只回退本次清理变更，恢复并复验清理前绿版本。发现并发修改则停机报告。禁止二轮清理。

## 工具异常停机

遇 `conflux`、`orca` 等外部工具报错，先核对对应 Skill 与 CLI `--help`。仍未覆盖就停机，原样报告命令与报错。禁止跨工作区翻源码或自行改外部工具。

## 外部写未决项门控

涉及 `git push`、PR/Issue（含 `Refs`/`Closes`）、发版等外部写操作，冻结草案须写死唯一默认值与执行归属。草案含未决选项且用户未明确选择时，禁止自行拍板或代跑，执行前必二次确认。已拍板动作仅在参数或目标变化时重批。

## 收尾、handoff 与 release 异常

验收后用 `worker-release` 关闭一次性终端，保留工作树；失败先查本次回执与终态，按 Orca 原生 release 恢复指南处理，未知时报告。
发布并核验 6 行 handoff；冲突保留原件，报告绝对路径与冲突内容，按约定用独立 ID 再发布。交付附绝对路径及可复制的续跑指令。

## 里程碑切新会话交接

里程碑验收通过、`max_turn_context_tokens >= 80000` 或同一问题连续 2 次无收敛时，发布并核验 6 行 handoff。需跨会话保留约束、已验证产物、被否决方案或下一步时，在同一交接目录写只读摘要（如 `<id>-notes.md`）并确认可读。输出可复制的新会话续跑首句：“读取已核验的 handoff（绝对路径）及随附摘要，按 Next 续跑。”
