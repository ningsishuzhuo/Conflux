# 摩擦日志

| 实战摩擦 | 影响 | 处理 |
| --- | --- | --- |
| 旧 `to` 对派单文本设 1,200 字硬截断 | 长契约可能丢失约束或验收细节 | 保留完整契约，可引用工作区文档路径。 |
| 协调者险些越权揽活 | 协调消耗执行额度，角色权限失焦 | 根规则明确协调职责，实施留给 Codex，配合原生权限。 |
| Orca 插件启动 Hook 调用传空 env | 授权标记无法稳定传给插件 | 由薄 CLI 显式校验本次付费授权。 |
| 真机试跑将 `--model default` 传给采用 `follow-client` 的 Orca 客户端 | 派单返回 `modelUnavailable` | 策略仍精确匹配 `default`，调用 Orca 时省略 `--model`。 |
